# ✈️ Tripora – Intelligent Travel Planner

**Plan smarter journeys. Explore further. Create memories.**

Tripora is a frontend-based travel planning web application developed using HTML, CSS and JavaScript. It helps users plan trips by entering their destination, travel duration and budget. The application generates a suggested itinerary, provides an estimated budget breakdown and allows users to save and manage their travel plans.

## 🌍 Project Overview

Tripora provides a simple and user-friendly interface for organising travel plans in one place. It includes popular destination displays, an interactive trip planner and a smart dashboard to track saved trips.

## ✨ Features

- **Home Page:** Attractive landing page with navigation.
- **Popular Destinations:** Displays popular destinations such as Goa, Manali and Bali.
- **Trip Planner:** Enter destination, number of days and budget.
- **Itinerary Generator:** Generates day-wise travel activity suggestions.
- **Budget Estimator:** Divides the total budget into four categories:
  - Hotel – 40%
  - Food – 25%
  - Transport – 20%
  - Activities – 15%
- **My Trips:** View previously saved travel plans.
- **Smart Dashboard:** Displays total trips, total planned budget and unique destinations.
- **Delete Trips:** Remove saved trips when required.
- **LocalStorage:** Saves trip details in the browser.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Open it in a web browser.
5. Enter a destination, number of days and budget.
6. Click **Generate My Trip**.
7. Save the generated trip and view it under My Trips.

## ⚙️ Working Principle

1. The user enters trip details.
2. JavaScript validates the entered information.
3. The application generates a suggested itinerary.
4. The total budget is divided into estimated expense categories.
5. The user can save the trip using browser LocalStorage.
6. The dashboard updates with the saved trip information.
